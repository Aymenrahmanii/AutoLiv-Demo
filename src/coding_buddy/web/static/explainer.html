Coding Buddy3 / 6 · how it works

Every script is reviewed twice

1R scriptLines are numbered so the model can point at one.
2Gemini reviewCode only and + Codebook in the prompt.
3JSON findingsLine, category and explanation, via a response schema.
4ScoreEach finding is compared with the ground truth.
Located

Points within ±2 lines of the injected error.

Right cause

Also names the real variable, code or rule.

False alarm

Any other finding, including on clean scripts.
